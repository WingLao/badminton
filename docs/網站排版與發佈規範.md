# 網站排版與發佈規範（badminton 網站）

最後更新：2026-11-15（澳門時間）
適用：GitHub 儲存庫 `WingLao/badminton` 及其本機來源資料夾
本文件是「怎樣命名、怎樣排版、怎樣發佈」的固定做法。內容規則（對象、免費影片、中英雙語測試等）仍以 `badminton/AGENTS.md` 和 `badminton/docs/網站維護規則.md` 為準；兩者衝突時，以使用者最新明確要求優先。

---

## 1. 命名與路徑（P23 起統一全部小寫）

### 1.1 網址格式

```text
https://winglao.github.io/badminton/<分類>/badminton-YYYY-MM-DD/
```

| 部分 | 規則 | 例子 |
|---|---|---|
| 儲存庫 | 固定 `badminton`（不可寫回早期錯字 `Badmionton`） | `WingLao/badminton` |
| 分類 | 英文小寫單字 | `learn`、`technology` |
| 期數資料夾 | `badminton-` ＋ 發佈日期（澳門時間 YYYY-MM-DD），全部小寫 | `badminton-2026-11-15` |
| 入口檔 | 每期資料夾一定有 `index.html` | `technology/badminton-2026-11-15/index.html` |

### 1.2 目前分類

| 分類 | 用途 | 本機來源資料夾 | 已發佈 |
|---|---|---|---|
| `learn/` | 羽球教學：YouTube 教學月報、學習精華（F1–F3） | `教學/YouTube月報_YYYY-MM/` | `learn/badminton-2026-11-15/` |
| `technology/` | 羽球科技：發球機、感測器、AI、器材、周邊 | `科技/` | `technology/badminton-2026-11-15/` |

新增分類：用一個英文小寫單字（例如 `equipment`、`tactics`），並同時建立 `<分類>/index.html` 分類目錄頁。

### 1.3 每期資料夾結構

```text
<分類>/
  index.html                 # 分類目錄：列出每一期，最新在最上面，底部「回首頁」
  badminton-YYYY-MM-DD/
    index.html               # 本期入口（主頁面）
    其他頁面.html             # 可選：完整版、核對表等，用中文檔名
    *.md                     # 可選：Markdown 文字版
    圖片/                     # 縮圖、圖表（本地保存，不熱連結）
    資料/                     # 可選：來源 JSON、核對紀錄
    assets/                  # 可選：共用 CSS / JS
```

### 1.4 每次發佈要同步的連結

1. 網站首頁 `index.html`：新增一張卡片，連到本期及分類目錄。
2. 分類目錄 `<分類>/index.html`：新增本期。
3. `README.md`：更新資料夾說明與線上連結。
4. 頁面內互相連結一律用**相對路徑**，例如 `../../learn/badminton-2026-11-15/…`。

## 2. 排版模式

### 2.1 頁面結構（由短到長，重點先行）

參考：`technology/badminton-2026-11-15/`

| 次序 | 區塊 | 目的 |
|---|---|---|
| 0 | 頂部導覽列（可橫向滑動）＋深淺色切換 | 手機一指跳段落 |
| 1 | 標題區：一句主題＋3–4 個數字卡 | 5 秒知道這頁是甚麼 |
| 2 | **一分鐘重點**：5–7 句，關鍵字加螢光底 | 時間有限只看這段 |
| 3 | **先看哪支**：中文影片優先，再列有中文字幕／看畫面就懂的外語片 | 不懂英文也能選片 |
| 4 | 三分鐘看懂：6 張重點卡＋月份時間線 | 掌握全貌 |
| 5 | 關聯圖（SVG）＋比較表 | 看到彼此關係 |
| 6 | 分類影片卡片 | 逐支細看 |
| 7 | 教學／訓練應用表 | 連到實際使用 |
| 8 | 名詞小字典 | 查英文術語 |
| 9 | 影片索引表＋資料依據說明＋外部來源 | 查證與追溯 |

`learn/` 的學生頁另依 `docs/網站維護規則.md`：一次顯示一個細節、一句提示、練習與單項檢查。

### 2.2 影片卡片固定欄位

1. 縮圖（`圖片/<影片ID>.jpg`，YouTube `mqdefault`，連回 YouTube）＋右下片長＋左上代號（如 M1、A2）
2. 日期（澳門時間）· 頻道 · 觀看次數 · 依據標記
3. 中文標題（意譯，不只翻譯原標題）
4. 💡 一句話重點（螢光底）
5. 🔊 原音語言｜不懂英文友善度 ★–★★★｜👀 看片建議（哪一段、有無中文字幕）
6. 摘要＋3–5 個要點（有章節時間碼就列出）
7. 「適合：」誰用／甚麼場合

### 2.3 依據標記與可信度

| 標記 | 意思 |
|---|---|
| A | 有原始資料：論文、開源程式、詳細技術文章、可讀字幕 |
| B | 依影片簡介與發布者章節 |
| C | 只有標題或新聞簡介，細節待看片確認 |

- 時間碼只用字幕或發布者章節，**不自行編造**。
- 未取得字幕時，頁面要寫明「重點依簡介／章節整理，不是逐字稿」。
- 沒有方法說明的誇大宣稱（例如「3 週進步 60%」）要標示為行銷內容。

### 2.4 視覺規範

- 顏色只用 `:root` 色彩變數；深色模式用 `@media (prefers-color-scheme: dark)` 和 `[data-theme="dark"]` 兩處定義。
- 分類色固定：發球機／機器人＝藍、感測／AI＝紫、器材＝綠、周邊＝橙、主色＝墨綠、強調＝螢光黃綠。
- 字體：系統字＋`PingFang TC` / `Noto Sans TC`；內文 16px，行高 1.7。
- 單一 HTML 檔、CSS 內嵌；除縮圖外不依賴外部資源。

### 2.5 手機規範（主要裝置是手機）

- Grid 一律寫 `minmax(min(XXXpx,100%),1fr)`，避免窄螢幕橫向溢出。
- **表格**：加 `class="cards"`；640px 以下自動變成一行一張卡片，每格前顯示欄名（由頁尾小段 JS 從表頭產生 `data-label`）。
- **關聯圖 SVG**：640px 以下隱藏，改顯示由上而下的 HTML 流程方塊（`.flow`），字體正常大小。
- 導覽列可橫向滑動；按鈕和連結夠大、易按。
- 發佈前截圖檢查：320、360、390、430px 手機，以及 768、1280px。

## 3. 內容規範（摘要）

- 繁體中文為主；使用者英文不好、時間有限 → 每支影片都要有中文一句話重點，外語片標明原音及看片建議，並附「開自動翻譯中文字幕」步驟。
- 教學文件須符合 P17 中英雙語中學生測試（見 `AGENTS.md`）。
- 推薦給學生的影片須核實可免費公開播放（未登入播放器狀態）；產品可能收費，要註明學生不需購買。
- 只收錄指定年份發布的影片；較早影片要標明年份。
- 保留影片原連結與本地縮圖，不下載影片本體。

## 4. 發佈步驟

1. `cd 到本機的 badminton 儲存庫資料夾` → `git status`：**先看有沒有其他人未提交的修改**；有就保留，不要一起提交。
2. `git pull --ff-only` 同步遠端。
3. 把本機成品複製到 `<分類>/badminton-YYYY-MM-DD/`（主頁命名為 `index.html`，連同 `圖片/`）。
4. 更新首頁、分類目錄、README 連結（第 1.4 節）。
5. 檢查所有相對連結都存在；手機與桌面尺寸截圖檢查。
6. `git add` 只加入本次相關檔案 → `git commit` → `git push origin main`（不可強制推送）。
7. 等 GitHub Pages 完成，下載線上頁面與本機檔案逐位元比對一致，圖片回應 200。
8. 在瀏覽器打開 HTTPS 線上網址，回報實際結果。
9. 本機成品與儲存庫副本保持一致：之後若有人在儲存庫改了頁面，要同步回本機來源。

## English summary

- **URL pattern:** `https://winglao.github.io/badminton/<category>/badminton-YYYY-MM-DD/` — all lowercase; date in Macau time; every issue folder has `index.html`. Categories now: `learn` (teaching digests) and `technology` (badminton tech). Each category has its own `index.html` listing issues.
- **On publish:** update the homepage, the category index and README; use relative links only.
- **Layout order:** headline + stat tiles → one-minute key points → "what to watch first" → six key changes + timeline → relationship diagram + comparison table → video cards → teaching use → glossary → video index + source notes.
- **Video card:** local thumbnail, date, channel, views, evidence tag (A/B/C), Chinese one-line takeaway, audio language + "friendly for non-English speakers" stars, key points, "best for".
- **Mobile first:** `minmax(min(Npx,100%),1fr)` grids; tables become stacked cards under 640px; SVG diagrams switch to a vertical HTML flow under 640px; check 320/360/390/430/768/1280px.
- **Deploy:** check for others' uncommitted work, pull, copy, verify links, commit only your files, push (no force), wait for Pages, byte-compare live page with local file, open the HTTPS URL.
