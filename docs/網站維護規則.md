# 網站維護規則

最後整理：2026-11-15。適用於 `WingLao/badminton` 的學生學習頁、教練科技頁與相關整理。

提示編號 P01、P02 等對應本機保存的原文紀錄；P24 是本次最新修正。部署是把已確認的網站版本發佈到公開網址。

## 最新強制規則（P24，羽毛球例外）

1. 本專案與羽毛球相關教學只需繁體中文，不需英文版或中英對照。
2. 教學交付前，扮演只懂中文的中學生，從頭閱讀並逐步照做。每步一件事，交代要做甚麼、輸入甚麼及預期結果；專有名詞首次出現用繁體中文解釋。卡住先修正，回覆交代測試及修正內容。
3. 每個答案先驗證；能執行的實際執行，能查原始資料的查原始資料。回覆說明驗證方法，不能核實的寫「未驗證」及原因。

英文學生測試依本次羽毛球例外不適用。P17 的一般雙語要求保留於歷史，不作本專案現行要求。

## 1. 讀者分眾與裝置

| 分類 | 主要讀者 | 內容與排版重點 |
|---|---|---|
| `learn/` 學習頁 | 國一至國三／F1–F3 學生 | 手機優先；一句提示、單一練習、單項檢查；短段落與大按鈕 |
| `technology/` 羽球科技 | 教練 | 訓練用途、實作條件、量測可信度、設備限制與使用成本；保留完整比較與來源，手機及桌機均可閱讀 |

兩類頁面都採繁體中文。學生頁保持有成長目標、易跟練的語氣；科技頁採教練分析語氣，不能把學生的信用卡條件套用到教練。

## 2. 學習方向

`learn/` 定位為「小選手，大目標」。把國際賽場當成長遠方向，讓學生明白今天該磨好哪一個細節。

每項學習內容應清楚交代：

1. 今天的一句提示。
2. 準備、擊球、下一拍要觀察的細節。
3. 可以實行的練習步驟。
4. 每次只記一項結果。
5. 從固定來球，逐步放進變化來球和短回合的方法。

保留圖片、表格、關聯圖與 Markdown（用簡單符號標示標題、清單與連結的文字文件格式），幫助學習及分析。學生不必先把整支影片看完；影片按重點定位，標明開始、結束時間，以及是否會自動停止。

## 3. 免費觀看是來源要求

學生沒有信用卡，`learn/` 推薦影片應可免費公開播放，不需要付費會員、付款或購買課程。對影片描述中的付費課程、器材與軟體，清楚說明它們不是本頁練習的購買要求。

科技頁優先引用可公開觀看的影片。器材或軟體本身可能收費，教練需另核對；影片免費不代表產品或訂閱免費，未核實時不給確切價格或效果結論。

本次採用未登入的 YouTube 播放器狀態與串流（播放時分段傳送的影音資料）可用性核對。會員專屬由播放器明確的會員提示確認。不能用 HTTP 200（只代表網頁成功回傳）、縮圖可見或「加入」按鈕來猜。

新增影片應保留核對日期與證據。未核實的先標為未核實；會員來源移出學生推薦。較早的免費基礎片可以補充，但須標明發布年份，不計作本月新片。

截至 2026-11-15 的修訂紀錄：原月報 26 支中，19 支可免費公開播放、7 支會員專屬；另核對補充片與科技頁後，共 60 支不同影片，53 支可免費公開播放、7 支已移出學生推薦。這是有日期的核對結果，未來新增或更新時應重新檢查，不能永久沿用這組數字。

## 4. 內容與依據

- 每個影片說明應點出技能及適用情境，不能只翻譯標題。
- 區分已讀字幕、發布者簡介／章節、未核實內容；不要把可播放說成已看完。
- 區分影片內容與本頁編製的練習、指標及成長路線。
- 替換影片時，同步修訂內容、片段時間、語言、縮圖、圖表、索引及必要的試練進度。
- 不把五項基礎細節說成完整的國際級選手培訓或資格標準。

## 5. 手機及維護檢查

以下是為落實上述要求而採用的維護做法。px 是像素，這裡表示檢查版面時採用的螢幕寬度單位。

- 有排版修改時，檢查 320、360、390、430px 手機寬度，以及 768、1280px 較大螢幕。
- 不應有橫向溢出；長文字及表格需能在手機上閱讀。固定按鈕要預留底部空間。
- 檢查選題、影片連結、展開內容、試練標記及資料儲存的相關行為。
- 試練標記只表示試過，不表示掌握；維持本機瀏覽器儲存的說明。
- 同步本機教學資料與部署副本；保留其他人的既有修改。

## 6. 提示保存

本對話可見的使用者提示原文已另存在本機「網站維護」資料夾。原文保留用字、拼寫、時間範圍選項與後續修正；本文件是整理後的規則，不冒充逐字原文。

後續要求先追加紀錄，再標明對哪條規則作新增或取代。保留過去要求，不能因改版而覆蓋整份歷史。未讀取的其他對話不得聲稱已完整保存。

## 7. 直接完成部署

使用者已要求直接完成部署。對此網站已授權的例行更新，完成適當檢查後提交（把本次修改記成一筆版本）並推送（同步到 GitHub）到 `main` 主要分支，等待 GitHub Pages（GitHub 提供的靜態網頁發佈服務）成功，再核對線上版本。

儲存庫是保存網站檔案和修改紀錄的位置。目前儲存庫為 `WingLao/badminton`；本期路徑為 `learn/badminton-2026-11-15/`。`Badmionton` 是早期拼寫，已被使用者修正，不可恢復。

完成後回報實際結果及公開連結。若受阻，說明具體原因；不要把尚未完成的部署說成已完成。

本次交付範圍是專案規則、提示保存及其部署。羽毛球網站適用 P24：全繁體中文，只做中文學生測試；英文版及英文學生測試不列為待完成事項。
