AVANCO 後台維護者只介紹做法

skill 是甚麼？ skill（技能包）是一個資料夾，裡面放一份 SKILL.md 說明書，和需要用到的小程式。AI 助手（例如 Codex、Claude Code）讀了說明書，就會按同一套步驟做事，不用每次重新解釋。

AVANCO 是羽球班的報名與管理系統，分成兩部分：

  • 報名網頁：家長和學生填報名表。
  • 後台（admin.html）：教練和行政人員看報名、記收支、點名。

下面兩個 skill 都是給維護這套系統的人用的。學生和家長不需要看。

為了安全，本頁不列出任何網址、帳號、密碼、資料庫名稱或伺服器設定。這些資料只保存在維護者自己的電腦裡。

兩個 skill 一覽

skill 名稱一句話用途甚麼時候用
avanco-cross-computer在另一部電腦把 AVANCO 系統架起來，並確認可以正常運作和發佈換新電腦、舊電腦環境壞掉、要在別的電腦繼續開發
avanco-activity-admin-template在後台新增一個活動分頁，照「暑訓第一階段」的完整版面複製新增營隊、課程期數、比賽、特訓等需要報名和記帳的活動

一、avanco-cross-computer：換電腦也能照樣運作

它解決甚麼問題：同一個系統要在不同電腦上開發時，每部電腦的工具版本和設定可能不一樣。這個 skill 把「檢查 → 安裝 → 啟動 → 驗證 → 發佈」寫成固定步驟，在 macOS 和 Linux 都能用。

名詞

  • FastAPI：用 Python 寫網站後端（處理資料的程式）的工具。
  • MongoDB：存放報名、學生、收支等資料的資料庫。
  • 環境變數：放在電腦設定裡、不寫進程式的秘密資料，例如資料庫密碼。
  • Render：把網站放上網的雲端服務。

做事步驟（每步一件事）

  1. 事前檢查：確認電腦有 Git、Python 3、curl 三個工具，並且在系統的資料夾裡。缺工具就先安裝，不要先改程式。
  2. 準備 Python 環境：建立一個獨立的 Python 環境，安裝系統需要的套件。
  3. 放入秘密資料：把資料庫連線資料設成環境變數，或寫在一個不會上傳的本機檔案。密碼從密碼管理器複製，絕不寫進程式或上傳。
  4. 在本機啟動：在自己電腦上開啟系統。
  5. 驗證：打開系統的「健康檢查」和「資料庫狀態」頁，兩個都正常才繼續；再打開首頁、報名表、後台各看一次。
  6. 發佈：把修改上傳到程式庫，雲端服務會自動更新，再到線上網址確認。

二、avanco-activity-admin-template：後台新增活動頁

它解決甚麼問題：每次新增活動（例如寒假營、比賽）都要做報名表、收支、點名。這個 skill 規定一律照「暑訓第一階段」最完整的版面複製，讓每個活動的畫面和計算方法都一樣。

每個活動頁由上到下的順序

  1. 標題列：活動名稱、篩選（例如組別）。
  2. 總數卡片：總收入、總支出、淨額。
  3. 報名摘要：報名人數、預估營收、未繳費人數。
  4. 報名表格：組別、姓名、日期、費用、繳費狀態等。
  5. 其他收支：其他收入、其他支出、淨額，加上輸入表單和紀錄表。
  6. 點名表：選組別和日期，勾選出席學生。
  7. 出席紀錄：每位學生出席了哪幾天、共幾堂。

計算規則（每個活動都一樣）

項目怎樣算
預估營收所有符合的報名費用加起來，不管有沒有繳費
總收入預估營收 ＋ 這個活動的其他收入
總支出這個活動的其他支出
淨額（頂部）總收入 − 總支出
淨額（其他收支區）其他收入 − 其他支出（不含報名費）

做事步驟

  1. 先確定活動資料：名稱、期間、報名分類、要不要點名、收支用哪個「範圍代號」（例如寒假營第一階段）。
  2. 照上面七個區塊的順序，複製出新的活動分頁。
  3. 每個畫面元素的名稱都加上活動代號，避免和其他活動混在一起。
  4. 收支紀錄同時用「範圍」和「期間」兩個條件篩選，每個活動的帳才不會混。
  5. 日期欄預設今天。
  6. 完成後檢查：程式語法沒有錯誤；打開後台，切到新活動分頁，確認七個區塊順序正確。
  7. 上傳時只放這次活動相關的檔案。
