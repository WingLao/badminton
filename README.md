# badminton

羽球教學月報與學習精華，透過 GitHub Pages 發佈。

學習頁採手機優先排版，文字面向 F1–F3 中學生：以五項成長細節選題，每項涵蓋準備、擊球、下一拍的觀察，並提供固定來球、變化來球到回合應用的練習路線。試練標記只保存在裝置瀏覽器，不會上傳，也不表示技能已掌握。
