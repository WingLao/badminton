TrackNetV3 ↗

qaz812345/TrackNetV3 · ★ 339 · 最後更新 2026-09-03

從一般比賽錄影逐格找出羽球位置的深度學習模型，V3 加入資料增強與軌跡修補（InpaintNet），補回被擋住或太快看不到的球。

訓練用途
取得每一格的球座標，再自行計算球速、落點分布、擊球點高度。
公開數據
作者 README 測試結果：準確率 97.51%、每秒 25.11 格（作者自己的測試集與硬體）。
條件與成本
要會 Python 與 PyTorch，有 NVIDIA 顯示卡較實際；模型權重要另外下載；只輸出座標，球速和落點要自己寫程式換算。

RallyLens ↗

YeonSeong-Lee/rallylens · ★ 25 · 最後更新 2026-09-03

一條指令把比賽影片變成球員骨架、球路尾跡、球場俯視小地圖與回合報告；整合 YOLO11-pose 骨架、ByteTrack 追蹤與 TrackNetV3 球路。

訓練用途
快速得到單打回合的跑動距離、站位分布與球路圖，適合賽後檢討。
公開數據
README 範例報告列出每位球員跑動距離（例如 40.3 公尺對 59.5 公尺）與站位區域比例。
條件與成本
要安裝 uv 與 ffmpeg；只自動挑選 2 名單打球員；回合文字報告用 Google Vertex AI Gemini 產生、輸出韓文，需要雲端帳號，費用未驗證。
授權
指令列工具 MIT、網頁版 AGPL-3.0（README 標示）

名詞小字典

名詞意思
GitHub放程式碼的網站；每個工具是一個「儲存庫」（repository，簡稱 repo），網址是 github.com/作者/名稱。
README儲存庫首頁的說明檔，寫功能、安裝方法和測試結果；本頁的數字都從這裡核對。
★ 星數GitHub 使用者按「收藏」的次數，可粗略看出多少人關注，不代表品質。
授權（License）規定可否修改、轉售；MIT 最寬鬆，AGPL-3.0 改了再公開提供要公開原始碼，「非商業」不可拿去賣。
git clone把整個儲存庫下載到自己電腦的指令；卡片底部「複製」按鈕複製的就是這行。
Python／PyTorch程式語言／深度學習工具；影像分析工具大多要用到。
顯示卡（GPU）電腦的繪圖晶片，AI 影像分析用它會快很多，NVIDIA 最常用。
骨架偵測（Pose）AI 在畫面中找出肩、肘、膝等關節點，連成火柴人，用來分析動作與站位。
透視校正（Homography）把斜角拍攝的球場換算成從正上方看的平面座標，才可以畫小球場和算跑動距離。
